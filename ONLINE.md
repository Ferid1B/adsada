# Онлайн-подключение

Проект работает без ключей в локальном режиме. Чтобы включить аккаунты и облачное сохранение:

1. Создайте проект Supabase.
2. Откройте SQL Editor и выполните обновлённое содержимое `schema.sql`. Скрипт сохраняет старые облачные сохранения, но защищённый рейтинг начнётся с серверного профиля и будет считать только бои, подтверждённые базой данных.
3. В Supabase откройте Project Settings → API и скопируйте Project URL и anon public key в `online-config.js`.
4. Загрузите в GitHub: `index.html`, `styles.css`, `app.js`, `online.js`, `online-config.js`, `schema.sql`, `README.md`.
5. Включите GitHub Pages для ветки `main` и корня репозитория.

Важно: `anon` ключ предназначен для браузера. Никогда не публикуйте `service_role` ключ. Таблица `player_saves` остаётся старым облачным хранилищем и не является доверенным источником рейтинга. Для соревновательных значений используется отдельная `ranked_progress`: клиент не может записывать в неё напрямую, а менять их могут только проверяющие RPC-функции после входа.

Онлайн-слой включает email-регистрацию, вход, выход, облачное сохранение и публичный рейтинг по серверному уровню и глубине. Инициализация рейтингового профиля создаёт нового героя первого уровня; старые значения остаются в прежнем облачном сохранении, но не переносятся в рейтинг, потому что их нельзя проверить задним числом. Клиент сохраняет отдельную копию прежних рейтинговых полей и не перезаписывает ими старое облачное сохранение. Рейтинговые бои начинаются и рассчитываются в Supabase; при ошибке сервера клиент не подменяет их локальным результатом. Публично выдаются только имя героя, уровень и глубина.

Незавершённый рейтинговый бой хранится на сервере и восстанавливается после перезагрузки страницы или повторного входа.

Для рейтингового героя сервер также хранит золото, зелья, инвентарь, экипировку, голод и полученные награды за задания. Покупка и продажа предметов, экипировка, еда, работа в порту и награды за задания проходят через проверяющие RPC; награда за работу ограничена одним разом в 30 минут. Экипировка учитывается сервером в уроне и защите. Старые предметы и деньги остаются в облачном сохранении и не копируются в новый рейтинг, поскольку клиентское сохранение нельзя считать доверенным.

Это защищает рейтинговые бои и основные операции рейтинговой экономики от прямой подмены из браузера. Обычные исследовательские находки и остальные клиентские системы всё ещё не серверно-проверены. PvP и полный перенос исследования на сервер требуют дальнейшей работы.
