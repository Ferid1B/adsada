# Онлайн-подключение

Проект работает без ключей в локальном режиме. Чтобы включить аккаунты и облачное сохранение:

1. Создайте проект Supabase.
2. Откройте SQL Editor и выполните содержимое `schema.sql`.
3. В Supabase откройте Project Settings → API и скопируйте Project URL и anon public key в `online-config.js`.
4. Загрузите в GitHub: `index.html`, `styles.css`, `app.js`, `online.js`, `online-config.js`, `schema.sql`, `README.md`.
5. Включите GitHub Pages для ветки `main` и корня репозитория.

Важно: `anon` ключ предназначен для браузера. Никогда не публикуйте `service_role` ключ. RLS-политики разрешают игроку читать и менять только собственное сохранение.

Сейчас онлайн-слой включает email-регистрацию, вход, выход и облачное сохранение. Игровая логика всё ещё клиентская; для защищённых рейтингов, валюты, PvP и общей игры следующим этапом нужен серверный API/Edge Functions, который будет проверять бой и награды.
