# БЕЗДНА: Колодец

Браузерная RPG с локальным режимом и онлайн-аккаунтами. Откройте `index.html` в браузере; сборка и установка зависимостей не нужны.

## Игровой цикл
Создайте персонажа → исследуйте случайные комнаты Колодца → выбирайте рискованные пути и ищите тайники → сражайтесь с обычными и элитными врагами → возвращайтесь в город с походной добычей → покупайте и надевайте снаряжение → выполняйте задания → победите хранителя прохода, чтобы открыть следующую глубину.

В подземелье есть ловушки, источники, тайники, припасы, рунические комнаты и элитные встречи. После каждого события маршрут случайно ведёт в другую комнату. На новых глубинах появляются более ценные предметы и опасные противники.

В городе доступна интерактивная карта поселения: через неё можно сразу попасть к Колодцу, рынку, таверне, гильдии, башне магов, постоялому двору или в порт. На рынке есть анимированный интерьер торговых рядов. В боях анимируются атаки, попадания, уклонения и лечение; анимации учитывают системную настройку уменьшения движения.

Без входа прогресс автоматически сохраняется в `localStorage` этого браузера. После входа доступно облачное сохранение и рейтинговый профиль; рейтинговые действия проверяются сервером Supabase. Вкладка «Как играть» позволяет скачать JSON-сохранение и импортировать его позже. Не размещайте файлы сохранения публично.

## Публикация тестовой версии на GitHub Pages
Загрузите файлы игры, включая `online.js`, `online-config.js` и `schema.sql`, в корень репозитория. В настройках GitHub Pages выберите публикацию ветки `main`, папка `/ (root)`. Аккаунты, облачные сохранения, рейтинг и PvP используют Supabase; для публикации SQL-схема должна быть применена к проекту.

## Технические ограничения
Локальное сохранение доступно для ручного редактирования и не считается защищённым серверным прогрессом. Баланс, комнаты и содержимое могут измениться.
