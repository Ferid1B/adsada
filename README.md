# БЕЗДНА: Колодец

Локальная браузерная RPG. Откройте `index.html` в браузере; сборка и установка зависимостей не нужны.

## Игровой цикл
Создайте персонажа → исследуйте Колодец → сражайтесь и собирайте добычу → вернитесь в город → покупайте и надевайте снаряжение → выполните задания → победите хранителя прохода, чтобы открыть следующую глубину.

Прогресс автоматически сохраняется в `localStorage` на устройстве игрока. Во вкладке «Как играть» можно скачать JSON-сохранение и импортировать его позже. Не размещайте файлы сохранения публично.

## Публикация тестовой версии на GitHub Pages
Загрузите `index.html`, `styles.css`, `app.js` в корень репозитория. В настройках GitHub Pages выберите публикацию ветки `main`, папка `/ (root)`. Это **одиночная тестовая версия**: у каждого игрока собственное локальное сохранение. Для общих аккаунтов, рейтинга и PvP необходим сервер с базой данных и серверным расчётом наград и боёв.

## Технические ограничения
Нет аккаунтов, общего прогресса, групп или PvP. Баланс и содержимое могут измениться. Сохранение в браузере доступно для ручного редактирования и не должно считаться защищённым серверным прогрессом.
